# Просто о сложном

Инструмент, который превращает сложный текст (инструкции к лекарствам, письма, документы)
в короткую и понятную версию. Сделан для людей с разными нарушениями: зрения, слуха,
с когнитивными особенностями, дислексией, а также для пожилых.

## Что умеет (прототип)

- Принимает текст или фото инструкции.
- Делает понятную карточку по разделам: для чего, как принимать, кому нельзя,
  с чем не сочетать, когда срочно к врачу, хранение.
- Дозировку показывает **дословно из оригинала**, чтобы не было ошибок.
- Режимы: «Кратко», «Очень просто», «По одной фразе» (одна мысль на экране), «Сложные слова».
- Озвучка, крупный шрифт (3 размера), высокий контраст, увеличенные интервалы.
- Можно задать вопрос по тексту.

## Как устроено

`app/index.html` — одна страница. Упрощение делает Claude: страница работает как
Artifact на claude.ai и использует возможности `sample` (запрос к Claude, включая фото)
и `tts` (озвучка). Если открыть файл просто в браузере, показывается только пример.
